# PulsePatch Lite — Architectural Decision Log

| Decision ID | Date | Context / Problem | Decision Made | Rationale & Trade-Offs | Status |
|---|---|---|---|---|---|
| **DEC-001** | 2026-10-30 | User requested training dataset from "taggel" | Identified "taggel" as phonetic spelling of **Kaggle** and specific research benchmarks (**PPG-BP Database** by Liang et al., **MIMIC-III Waveform**, **UCI Cuff-less BP**) | Ambiguity resolved by searching research literature and official repositories; will support both official Kaggle/Figshare PPG-BP download and local CSV acquisition pipelines. | `ACCEPTED` |
| **DEC-002** | 2026-10-30 | Multi-agent execution model vs sequential execution | Adopt a unified Principal Agent Orchestrator with structured, modular domain skills in `.agents/skills/` executed sequentially with strict provenance tracking | Current tool environment operates in single-session orchestration; modular skills prevent context pollution while enforcing separation of concerns. | `ACCEPTED` |
| **DEC-003** | 2026-10-30 | SpO₂ Calculation Pipeline | Move SpO₂ from "reserved/null" to active dual-channel computation (Red & IR AC/DC ratio-of-ratios calibration: $R = \frac{AC_{red}/DC_{red}}{AC_{ir}/DC_{ir}}$) in both firmware and Dart fallback | Hardware MAX30102 has dual LEDs; previous firmware read IR only for BPM. Adding dual-channel support unlocks actual physiological pulse oximetry. | `ACCEPTED` |
| **DEC-004** | 2026-10-30 | Blood Pressure Model Runtime | Train models in Python (scikit-learn / gradient boosting) and export model weights/coefficients directly into **Pure Dart** background isolate | Eliminates dependency on heavy C++ binary runtimes (like TFLite/ONNX) which introduce build and ABI complications on physical devices. | `ACCEPTED` |
| **DEC-005** | 2026-10-30 | Doctor Discovery & Map Provider | Implement OpenStreetMap / Overpass API and Google Places/OSM fallback with geolocation permissions and manual city selection | Complies with privacy directives (no health data transmitted to map service) while supporting location search in Egypt without forced API billing blockers. | `ACCEPTED` |
