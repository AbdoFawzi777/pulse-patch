# Medical Dataset Engineering Skill

## 1. Purpose
Provides protocols for discovering, downloading, sanitizing, synchronizing, and structuring clinical and physiological benchmark datasets (such as Kaggle, PPG-BP, MIMIC-III, VitalDB, and PhysioNet) with strict compliance to privacy, licensing, and ethical guidelines.

## 2. When to Use
- Resolving external dataset names, official domains, and authorized mirror locations.
- Inspecting data integrity, sampling frequency consistency, and signal-to-reference time synchronization.
- Generating subject-wise splits to prevent patient data leakage between training, validation, and test cohorts.
- Creating reproducible data ingestion scripts and manifest files.

## 3. Required Inputs
- Target dataset name or repository link (e.g., Kaggle PPG datasets, Figshare PPG-BP).
- Licensing terms (CC-BY, PhysioNet Credentialed Access, Open Data Commons).
- Raw data files (CSV, WFDB, MAT, HDF5, Parquet).

## 4. Expected Outputs
- `dataset_manifest.json` detailing subject count, sampling frequency, sensor hardware, and SHA-256 checksums.
- Cleaned tabular data files with standardized column conventions (`subject_id`, `age`, `gender`, `sbp`, `dbp`, `ppg_waveform`).
- Stratified cross-validation fold indexes based strictly on `subject_id`.

## 5. Practical Workflow
1. **Source Authentication:** Verify the official provenance and publisher of the dataset. Confirm whether access requires credentials (e.g., CITI training for MIMIC) or is public open data.
2. **Quality Screening:** Scan waveforms for flatlines, saturation, non-physiological pressure values ($SBP < 60$ or $SBP > 240\text{ mmHg}$), and missing channels.
3. **Synchronization Audit:** Ensure reference blood pressure readings correlate temporally with the recorded PPG waveform segments.
4. **Subject Stratification:** Group all beats/segments from an individual subject together. Never perform random record-level shuffling across splits.

## 6. Verification Criteria
- Zero subject overlap between training folds and test folds ($\text{Subjects}_{train} \cap \text{Subjects}_{test} = \emptyset$).
- Checksums verified and recorded in `DATASET_PROVENANCE.md`.

## 7. Known Limitations & Prohibited Shortcuts
- **Prohibited:** Never bypass PhysioNet or credentialed access agreements.
- **Prohibited:** Never commit identifiable patient health information (PHI) to git.
- **Prohibited:** Never train on synthetic labels generated by another unverified AI model.
