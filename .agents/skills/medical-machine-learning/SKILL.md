# Medical Machine Learning Skill

## 1. Purpose
Defines methodologies for training, evaluating, selecting, and deploying mathematical and machine learning models for pulse classification and blood pressure estimation, with seamless deployment to mobile client runtimes without heavy binary dependencies.

## 2. When to Use
- Comparing linear baselines against non-linear architectures (Multi-Layer Perceptrons, Decision Trees, Gradient Boosting).
- Performing feature normalization (Z-score, MinMax) and tracking parameter bounds.
- Exporting trained model weights, intercepts, scaling parameters, and metadata to JSON/Dart structures.
- Verifying exact mathematical parity ($\Delta = 0.000000$) between Python training forward passes and Flutter on-device execution.

## 3. Required Inputs
- Preprocessed feature matrices with target labels ($SBP$, $DBP$, pattern classifications).
- Cross-validation splits generated by `medical-dataset-engineering`.
- Deployment target constraints (pure Dart isolate, $<1\text{ ms}$ inference budget, $<50\text{ KB}$ weight payload).

## 4. Expected Outputs
- `weights.json` and `model_meta.json` containing layer coefficients, bias vectors, feature scalers, and input definitions.
- Model performance evaluation metrics (MAE, RMSE, $R^2$, Confusion Matrix).
- Flutter inference service running inside a dedicated background isolate.
- Verification parity script proving numerical identity between Python and Dart outputs.

## 5. Practical Workflow
1. **Model Selection & Training:** Train candidate regressors and classifiers. Log training, validation, and test fold metrics.
2. **Error & Subgroup Analysis:** Evaluate performance across age groups, normotensive vs. hypertensive ranges, and resting vs. post-activity states.
3. **Parameter Extraction:** Dump model weights and normalization parameters to structured JSON.
4. **Pure Dart Implementation:** Implement matrix multiplication, bias addition, and activation functions directly in Dart vectors.
5. **Parity Check:** Execute synthetic and real test vectors in both Python and Dart; assert maximum absolute difference $< 10^{-6}$.

## 6. Verification Criteria
- Exact parity between Python and Dart inference ($\Delta < 0.000001$).
- Background isolate execution time $< 1.0\text{ ms}$ on target mobile hardware.

## 7. Known Limitations & Prohibited Shortcuts
- **Prohibited:** Never claim model accuracy without reporting test set performance on unseen subjects.
- **Prohibited:** Never deploy models with untracked normalization statistics.
- **Limitation:** Pure Dart neural networks are ideal for small-to-medium models ($<100,000$ parameters); very deep CNNs require dedicated acceleration.
